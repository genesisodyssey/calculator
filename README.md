# Simple Calculator

A small browser calculator built with plain HTML, CSS and JavaScript. No dependencies, no build step.

## Features

- Add, subtract, multiply, divide and modulo
- Decimals, clear (C) and backspace
- Chained operations (2 + 3 + 4 = 9)
- Divide-by-zero shows "Error"
- Keyboard support: digits, `+ - * / %`, `.`, Enter or `=`, Backspace, Escape

## Run it

Open `index.html` in any browser. That is it.
